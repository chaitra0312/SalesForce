# Day 5 - Apex Service Layer

## Objective

Learn Apex Classes, Methods, SOQL and DML by implementing an Order Service.

## Concepts Covered

- Apex Classes
- Methods
- Access Modifiers
- SOQL
- DML
- Business Logic
- OOPS
- Encapsulation

## Methods Implemented

- placeOrder()
- checkStock()
- calculateTotal()
- processPayment()
- createOrder()
- createOrderItem()
- createShipment()

## Learning Outcome

Understood how business logic can be separated into reusable methods using Apex classes.
