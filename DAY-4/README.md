# Salesforce Interview Readiness Bootcamp - Day 4

## Topic
Lightning Web Components (LWC)

---

## Objective

The objective of this task was to understand the basics of Lightning Web Components by creating the user interface for an E-Commerce application using HTML, JavaScript, and Meta XML.

---

## Activities Completed

### Part 1
- Understood the purpose of Lightning Web Components.
- Learned the Salesforce architecture (LWC → Apex → SOQL → Database).

### Part 2
- Learned the LWC folder structure.
- Understood the purpose of:
  - HTML
  - JavaScript
  - Meta XML

### Part 3
Created the first Lightning Web Component named **homePage** and deployed it to a Lightning App Page.

### Part 4
Created JavaScript variables and displayed them in HTML using Data Binding.

Variables Used:
- Customer Name
- Today's Date
- Total Products
- Total Categories
- Cart Items
- Status

### Part 5
Created a **Shop Now** button.

When clicked:
- Cart Items changed from **0** to **1**
- Status changed from **Cart Empty** to **Item Added to Cart**

### Part 6
Implemented status change using only JavaScript without Apex or Database.

### Part 7
Developed the first screen of the E-Commerce Home Page.

Displayed:
- Welcome Message
- Today's Date
- Total Products
- Total Categories
- Cart Items
- Status
- Shop Now Button

### Part 8
Performed Data Binding by changing the value of the `customerName` variable and observing the UI update automatically.
